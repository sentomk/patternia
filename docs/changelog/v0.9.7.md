# Patternia v0.9.7 Hotfix Release Note

**Release Date:** November 2026
**Version:** 0.9.7
**Type:** Hotfix

---

## Overview

Patternia v0.9.7 is a hotfix release for v0.9.6. An installed copy of
v0.9.6 does not compile: four headers added in v0.9.6 were left out of
the install, so `#include <ptn/patternia.hpp>` fails with a
missing-file error. v0.9.7 installs every header. The library code is
the same as in v0.9.6.

If you use v0.9.6 through vcpkg, `cmake --install` or
`find_package(patternia)`, upgrade to v0.9.7. Code that uses the source
tree directly (an include path, `add_subdirectory` or `FetchContent`)
was not affected.

---

## Bug Fixes

### Installed package missing headers

`CMakeLists.txt` installed the headers named in a hand-written list,
and the four headers added in v0.9.6 were never added to it:

- `ptn/core/common/index_switch.hpp`
- `ptn/core/common/inline.hpp`
- `ptn/core/common/owned_eval.hpp`
- `ptn/pattern/plain_value.hpp`

The public headers are now collected from `include/ptn` with
`file(GLOB_RECURSE)`, so a new header is installed without a list to
update. ([#113](https://github.com/sentomk/patternia/pull/113))

## Internal Improvements

- New CTest test `install.consumer`: it installs the build tree into a
  scratch prefix, checks that every header under `include/` was
  installed, and builds and runs a program that finds the package with
  `find_package(patternia)`. It runs with the rest of the suite on
  every CI configuration.

## Impact

- API surface: unchanged.
- Runtime semantics and generated code: unchanged.
- Install: `cmake --install` and package managers now ship every
